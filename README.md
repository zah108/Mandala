# 🎨 Mandala Generator

Процедурный генератор мандал на Python с использованием библиотеки `turtle`. Создаёт уникальные симметричные рисунки с настраиваемыми стилями, цветами и геометрией.

![Mandala](https://img.shields.io/badge/Python-3.8+-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

## ✨ Возможности

- **11 стилей центра**: радиальные лучи, концентрические круги, спираль, внутренние петли, мишень, звезда Давида, символ Ом, цветок, лотос, солнце, узел
- **12 стилей разделительных лент**: штрихи, круги, зигзаг, квадратики, полукруги, волны, ромбы и другие
- **17 стилей слоёв лепестков**: пламя, листья, перья, капли, ромбы, веера, дубовые листья и другие
- **Гибкая система цветов**:
  - 4 семейства палитр (тёплые/холодные × мягкие/яркие)
  - Автоматический выбор без смежных цветов
  - Взвешенный случайный выбор
  - Режимы: всегда включена / выключена / случайно
- **Автоматическое логирование** с таймингами фаз
- **Экспорт в PDF/JPG** через Ghostscript или PIL
- **Настраиваемая скорость отрисовки** (от мгновенной до плавной анимации)

## 📋 Требования

- Python 3.8+
- `turtle` (входит в стандартную библиотеку)
- `Pillow` (для экспорта изображений)
- `Ghostscript` (опционально, для экспорта в PDF)

### Установка зависимостей

```bash
pip install Pillow
```

Для экспорта в PDF установите Ghostscript:
- **Windows**: [Скачать Ghostscript](https://ghostscript.com/releases/gsdnld.html)
- **macOS**: `brew install ghostscript`
- **Linux**: `sudo apt-get install ghostscript`

## 🚀 Использование

### Быстрый старт

```bash
python mandala-29.py
```

Программа автоматически:
1. Сгенерирует случайную мандалу
2. Отрисует её в окне turtle
3. Сохранит в формате PDF/JPG в папку `img/`
4. Запишет лог генерации в папку `log/`

### Настройка параметров

Откройте файл `mandala-29.py` и измените класс `Config`:

```python
class Config:
    # Режим раскраски: "yes", "no", "random"
    COLOR_MODE = "yes"

    # Выбор палитры: "all", "random", "warm_soft", "cool_soft", "warm_bright", "cool_bright"
    PALETTE_CHOICE = "warm_bright"

    # Скорость отрисовки: 0-8 (быстро), 9 (мгновенно), 10-20 (плавно)
    DRAW_SPEED_LEVEL = 8

    # Формат сохранения: "pdf" или "jpg"
    SAVE_FORMAT = "pdf"

    # Геометрия мандалы
    CIRCLE_RADIUS = 45
    BAND1_WIDTH = 12
    L1_WIDTH = 55
    # ... и так далее
```

## 🎨 Режимы раскраски

| Режим | Описание |
|-------|----------|
| `"yes"` | Раскраска всегда включена |
| `"no"` | Раскраска всегда выключена (чёрно-белая мандала) |
| `"random"` | Случайный выбор при каждом запуске |

## 🌈 Палитры цветов

| Палитра | Описание |
|---------|----------|
| `"all"` | Все цвета из всех семейств |
| `"random"` | Случайное семейство при каждом запуске |
| `"warm_soft"` | Тёплые пастельные тона |
| `"cool_soft"` | Холодные пастельные тона |
| `"warm_bright"` | Насыщенные тёплые тона |
| `"cool_bright"` | Насыщенные холодные тона |

## 📊 Логи

Каждая генерация записывается в лог-файл `log/YYYY-MM-log.txt` с информацией:
- Дата и время генерации
- Режим раскраски и палитра
- Выбранные стили для каждой области
- Использованные цвета
- Тайминги фаз (если включено)

Пример лога:
```
==================================================
Генерация Мандалы
Дата: 2026-01-15 | Время старта: 14:23:45
Раскраска: включена (режим: yes)
Семейство цветов: warm_bright (Тёплое-яркое)
Скорость рисования: 8 (пауза 0.00000 с, пачка 15 шагов)
--------------------------------------------------
 Выбранные узоры по областям:
  1. Центральный круг:      Вариант 7 (Ом) [цвета: #f4a261 #e76f51]
  2. Разделительная лента 1: Вариант 3 (Зигзаг) [цвет: #e9c46a]
  3. Уровень 1:              Вариант 4 (Классический лист) [лепестки: #bc4749 #bc6c25; кольцо: #d97642]
  ...
--------------------------------------------------
 Статус: Успешно сохранено -> img/2026-01-15-mandala-12345.pdf
 Время окончания: 14:24:12
==================================================
```

## ⚙️ Расширенные настройки

### Включение таймингов

```python
TIMING_ENABLED = True
```

Покажет время выполнения каждой фазы в консоли и логе.

### Отключение заливки колец

```python
PAINT_LAYER_RINGS = False
```

Отключит фоновую заливку колец под слоями лепестков.

### Изменение геометрии

Меняйте радиусы и ширины для создания мандал разного размера:

```python
CIRCLE_RADIUS = 60      # Больше центр
BAND1_WIDTH = 20        # Шире ленты
L1_WIDTH = 80           # Выше слои лепестков
```

## 🐛 Troubleshooting

### Ошибка: "Ghostscript не найден"

Установите Ghostscript (см. раздел "Требования") или измените формат сохранения:

```python
SAVE_FORMAT = "jpg"  # Вместо "pdf"
```

### Ошибка: "No module named 'PIL'"

Установите Pillow:

```bash
pip install Pillow
```

### Мандала рисуется слишком медленно

Увеличьте скорость:

```python
DRAW_SPEED_LEVEL = 9  # Мгновенная отрисовка
```

### Окно turtle не открывается

Убедитесь, что у вас есть графический интерфейс. В headless-среде (сервер без монитора) turtle не работает.
